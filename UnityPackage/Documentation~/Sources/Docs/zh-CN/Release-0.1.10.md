# 0.1.10 正式版 · 变更与验证范围

2026-10-16，面向 RimWorld 1.7.4980 rev60、.NET 10。本版延续 0.1.9 Preview 的内置运行时和 Inspector 风格设置页，增加地图载入阶段的渲染预热提示。

## 渲染预热

- 预热期间使用原版加载背景，显示中文或英文的“正在预热渲染管线”及已处理任务数 / 总任务数。
- 原版黑色淡入遮罩在预热等待期间不覆盖加载提示；其他时段沿用原版行为。
- 地图管线分帧执行，每批最多 16 项或约 8 ms；先展示提示，再构建计划。屏幕特效通过现有入口在单独一帧预热。
- 超时后在批次边界取消剩余工作；渲染目标重建时重新生成预热计划，完成或失败后释放请求。

单次显卡驱动调用无法中断，计划构建和屏幕特效预热也不受逐项时间预算限制。因此本版旨在让加载状态可见，不保证每帧耗时上限或缩短总加载时间。详见[资源载入](ResourceLoading.md)。

## 分发与兼容

独立模组、内置运行时和 Unity 导出工具统一为 0.1.10，提供 SHA-256 校验文件。程序集身份仍为 1.0.0.0，内置协议仍为 1；targets 默认最低 API 版本保留 0.1.9。

启用独立前置时始终使用独立版；要获得本次预热提示，需要更新实际选中的运行时。没有独立前置时选择最新兼容内置包，相同副本仍只运行一次。References 仅供编译，不作为额外运行时复制。框架不包含真实 Unity 引擎、游戏程序集或 Harmony，也不联网检查或下载更新。

## 本次验证

- Core、主运行时、Spine、Embedded、ShaderTool 和 Unity 导出工具源码编译通过。
- 预热批次、取消与超时相关验证源码编译通过，本次未执行这些运行时测试。
- 静态核对进度读取、渲染线程调用、原版加载窗口与淡入遮罩的补丁范围，以及中英文提示。
- 核对发行包版本、程序集身份、内置资源与许可、编译引用、离线说明书和 SHA-256。
- 保留第三方 Spine 的 3 个 CA2022 警告和导出工具的 5 个旧粒子枚举弃用警告。

本次没有启动 RimWorld 或 Unity；新增预热提示尚未进行游戏内目视验证，地图长期渲染和所有 UI 缩放也未完成回归。

## 先前验证

0.1.9 Preview 已完成 .NET 10 离线选择与加载检查，以及三个测试模组在有 / 无独立前置时的真实游戏启动；包括运行时单例、Def 单例、内容归属和派生脚本实例。5,002 项登记列表的开销检查在离线环境完成。测试临时文件已清理。

这些是前一版本的验证记录，本次没有重跑，不能视为 0.1.10 的游戏实测。完整范围见 [0.1.9 Preview 验证记录](Release-0.1.9.md)。
