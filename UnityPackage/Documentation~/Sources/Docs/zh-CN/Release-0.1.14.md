# 0.1.14 正式版 · 更新说明

2026-10-18，适用于 RimWorld 1.7 / .NET 10，资源制作使用 Unity 2022.3。

- 完善 Generic Avatar 的动画路径绑定，支持 Legacy Animation 按 Renderer 可见性裁剪；减少重复的骨骼矩阵上传和 Transform 矩阵计算。
- 蒙皮网格支持适配自定义材质的顶点程序、多 Pass 与阴影，修正骨骼矩阵布局，并按子网格规则绘制附加材质。
- 粒子噪声改用连续三维旋涡场，复用相机投影与可见性计算，减少不需要碰撞时的物理数据准备；修正拖尾朝向与 GrabPass 纹理绑定。
- 优化 UGUI 的投影、遮罩、裁剪和层级收集，减少重复计算与临时分配；完善相机绘制排序及 R8/R32 单通道离屏纹理分配。
- 导出工具支持独立 Shader 的多 Pass 和默认参数，完善 ForwardBase 光照、阴影及法线矩阵转换；符合条件的可读 DXT1/DXT5 贴图保留原始压缩块和 mip 链。
- 独立版恢复提前加载，以兼容普通 C# 模组，并按实际程序集归属识别运行时；未启用独立版时选择满足内容要求的最高兼容内置版本。
- 完善构建与 CI 入口、固定 .NET 10 SDK 版本；改进游戏验证时的模组备份恢复，修复点引用覆盖游戏目录参数及首次安装清理误报。

升级时同时更新导出工具和实际使用的运行时；涉及动画绑定、Shader 或贴图导出改进的资源应重新导出。独立版和内置版都需要 Harmony。启用独立前置时优先使用独立版；C# 内容模组使用内置包的 `.targets` 发布延迟脚本，`References` 仅供编译，不要复制进模组加载目录。程序集身份保持 `1.0.0.0`，内置协议保持 `1`。

发布文件：

- `RimUnity-0.1.14.zip`：独立模组本体，解压到游戏 `Mods`。
- `RimUnity.Embedded-0.1.14.zip`：供内容模组集成的内置运行时、编译引用及接入文件。
- `com.chezhou.rimunity-0.1.14.tgz`：Unity 导出工具，在 Package Manager 中安装。
- `SHA256SUMS.txt`：上述三个包的 SHA-256 校验值。
