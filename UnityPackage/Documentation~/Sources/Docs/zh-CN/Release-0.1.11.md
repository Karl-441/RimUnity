# 0.1.11 正式版 · 更新说明

2026-10-16，适用于 RimWorld 1.7.4980 rev60 / .NET 10。

- 导出并支持粒子 Renderer 的 `minParticleSize` / `maxParticleSize`。最大尺寸为 0 时隐藏粒子面片，保留模拟和拖尾，修复此类特效出现白点的问题；网格粒子不受此限制。
- 修正粒子拖尾面片朝向，避免被背面剔除而消失。
- 支持运行时创建的 FullRect Sprite 自动生成矩形渲染几何；导出的 Tight Sprite 继续使用原始几何，缺失时明确报错。

已有特效需要用 0.1.11 导出工具重新导出，才能携带粒子尺寸参数；同时更新实际使用的独立或内置运行时。启用独立前置时仍优先使用独立版。程序集身份保持 1.0.0.0，内置协议保持 1。

提供独立模组 `RimUnity-0.1.11.zip`、内置运行时 `RimUnity.Embedded-0.1.11.zip`、Unity 导出工具 `com.chezhou.rimunity-0.1.11.tgz` 和 `SHA256SUMS.txt`。

验证：运行时和导出工具编译、静态资源核对；未启动游戏进行画面验收。保留 Spine 的 3 条既有 CA2022 警告，以及导出工具使用旧粒子枚举的 5 条 CS0618 警告。
