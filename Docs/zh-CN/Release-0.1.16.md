# 0.1.16 正式版 · 更新说明

2026-10-21，适配 RimWorld 1.7.4984 rev1242 的 Waylith 引擎更新。

- 修复游戏更新后进入地图时，后处理接口变化导致的崩溃。
- 修复屏幕特效释放纹理绑定时的空引用错误。
- 优化粒子坐标转换和顶点数据生成，减少重复计算。
- 完善特效性能诊断，区分测试场与背景粒子的数量和渲染来源，帮助定位性能开销。

请先更新游戏，再更新 RimUnity。使用内置运行时的内容模组也需要更换内置包；C# 内容模组通过包内 `.targets` 重新发布。独立版和内置版均需要 Harmony。1.6 保留兼容占位，不加载运行时功能。

发布文件：

- `RimUnity-0.1.16.zip`：独立模组，解压到游戏 `Mods`。
- `RimUnity.Embedded-0.1.16.zip`：供内容模组集成的内置运行时、编译引用及接入文件。
- `com.chezhou.rimunity-0.1.16.tgz`：Unity 导出工具，在 Package Manager 中安装。
- `SHA256SUMS.txt`：发布包的 SHA-256 校验值。
